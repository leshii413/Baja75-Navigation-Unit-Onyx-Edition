Baja75 Navigation Unit (formerly Tread XL - Baja75 GPS)
10" Off-Road Race Navigator - by Baja75

Seven editions (install ONE, and remove any older Tread XL zip): the full unit (Chase, Adventure, Rally, Track), the
Chase Edition (Chase mode only; pits, start / finish, VCPs and speed zones, no pacenotes or hazard markers), the Rally
Edition (Rally mode only), the Track Edition (Track mode only), the free Common Edition (all four modes with map, music, course import, racing, Times and
2 courses of your own and video; no MARK or Chase Map) and the Free Edition (Adventure mode, map, music,
course import, racing, 1 course of your own; everything else opens on a Baja75 server or with a product key) and the
Onyx Edition (road / overland exploring, no racing: home screen, music, your own videos, map, Gallery, 3 routes,
hazard / turn / note markers; metallic black case).
On a Baja75 server every edition has every feature. Off the servers: recording asks for the password (full unit, Chase
and Rally Editions). The full unit also asks for it for modes, CHASE, MARK, split screen, the Record / Waypoints /
Display tabs and sharing out (Export GPX, server pack); map, Courses, Times, racing and Import GPX stay open. Unlocked
until the game closes. The Common Edition has no password: 2 courses of your own (delete one to make room), recording in
single player only (not on other BeamMP servers).

Unlocking: on a Baja75 or Leshii413 server everything is open. Off the servers enter a password or license key in
MENU > Display > License; a personal-use license can be bought from Baja75 on Patreon.
Video plays big with the map small in a corner (Display: corner, music as a card or a screen).

Power button (far right of the bezel, by the green light): Restart System restarts the GPS screen.

As the Baja75 owner, I wanted a method for racers to complete a race on and offline. This is my first attempt at doing so.

Baja chase navigator look: rolling waypoint list, tappable data fields, race miles, VCP cleared/missed,
speed zones with overspeed warning, off course / wrong way alerts, Chase Map (track another BeamMP
player or any AI car, live or delayed like satellite team tracking), the level's terrain + roads, and the
other vehicles around you (players and AI, with names).

REC button on the main screen records a course; MARK drops VCPs, speed zones, pits, hazards and turn left / right markers.
Racing: with any course loaded press START (left of REC). On the line it counts down 10 s and times you to the
finish; elsewhere tap TO START twice to be moved to the line. MENU > Times lists every run, and
settings/TreadXLGPS/race_log.txt keeps a record of each (date, time zone, map, course, time, vehicle, warnings, resets,
recoveries, every off-course moment with when / where / how long, and the parts damaged in crashes; from v3.1.5 also
your driver name and race number, the exact time in ms, VCPs, session and a run id). Results stay 90 s.
MENU > Times > Export for scoring saves a copy named after you (settings/TreadXLGPS/exports) for the race organizer.
On a BeamMP server with the Baja75 results collector (Adventure, Rally, Track and Chase Editions), runs on the
server's courses are also sent to the server automatically ("Result sent to the server").
Sign in (Adventure, Chase, Rally, Track Editions): your username goes on every recording and timed run (no password).
On a BeamMP server your BeamMP name is used (not as a Guest); offline or after leaving a server, sign in to record or race.
Baja75 Navigation Unit Alerts: a second HUD app with big flashing Wrong Way / Off Course / Slow Down warnings - place it anywhere.
Rally pacenotes: MARK > Rally pacenote (or Auto pacenotes from the course line) - BeamNG's own pacenote tiles and
co-driver voices read the notes ahead of each corner while you drive a saved route. Off course warns from 15 m.
Display options: dark mode, computer or in-game clock, next VCP / next pit cards, sounds (start-up chime, countdown).
Courses are saved in your BeamNG user folder under settings/TreadXLGPS/<map>/ (MENU > Courses > Open folder).
Name boxes: click and type, or press the keyboard button next to the box to type in a small game window.
Share them as GPX files (MENU > Share) or as a server pack zip for a BeamMP server's Resources/Client. Both also save a
1920x1080 course map picture (<name>.map.jpg, game map or satellite) and <name>.info.txt (course, map, distance, elevation).
With a route loaded the CHASE button reads CO-PILOT MODE; the button under TRK UP centers the map on you.
Five buttons under the screen: MODE (Chase / Adventure / Rally / Track), DISPLAY (map / video / music / gauges), 3 for later.
Chase: direction-only co-driver calls + music bar. Adventure: split screen. Rally: full calls + music bar. Track: gauges.
Music waits while the co-driver reads (Chase / Rally; Display > Music with co-driver calls). Album art from the files.
Video: paste a YouTube link. The GPS tries a page with a web address (your own page, https://leshii413.github.io/yt.html,
http://localhost:37575) to get past YouTube's "Error 153", but BeamNG's screen only opens YouTube's own pages, so
WEB (browser / Steam overlay) is the way to watch YouTube. Display > Check sites lists what the screen opens. WebM files from settings/TreadXLGPS/videos always play. Full screen video: the arrows button in the video controls (or its key) fills the whole screen, or the whole split side with split screen on. Music: drop MP3 / OGG / FLAC / WAV files in
settings/TreadXLGPS/music. Buttons and media keys (volume, mute, play/pause, next, previous) bind in Options > Controls.
Danger / hazard markers on a course flash 3 times on the alerts when they come up.
Baja75 Navigation Unit Pacenotes: a third HUD app that pops up the pacenote tiles as each note comes up (Display > Rally pacenotes:
when called / next notes / off). Full GPS, Rally and Common Editions.
Up next also lists the drivers ahead of you on the course (ON ROUTE): only drivers in a vehicle and on the course line.

Install: put the mod zip in mods/ (single-player) or Resources/Client/ (BeamMP server).
Keep only ONE Baja75 Navigation Unit zip in mods - delete older versions (a red banner on the GPS warns you).
Add "Baja75 Navigation Unit" (or your edition: Chase / Rally / Common Edition) from the HUD apps list.
Controls: Options > Controls, search "Baja75" (record, mark waypoint, chase next, zoom, orientation).
